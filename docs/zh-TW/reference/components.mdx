元件是叢集管理員在每個叢集安裝一次的軟體。Zeabur Catalog 依 capability（用途類別）寫明採用哪個上游 chart、哪個版本、哪些設定，以及選擇原因。你可以依下表查看各元件在單節點與多節點的預設狀態。

各 profile（`single-node` 或 `multi-node` 的設定組合）使用以下狀態：

- 預設啟用（`recommended`）：預設開啟。
- 選用（`optional`）：提供選項，但預設關閉。
- 不支援（`unsupported`）：不提供選項。

各元件檔案的 `detection` 規則會找出既有安裝，供系統重複使用。
