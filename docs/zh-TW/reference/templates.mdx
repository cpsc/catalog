專案成員可以選擇範本，將應用程式安裝到單一 Namespace。每個範本固定映像檔、設定資源要求與上限，並在可行時採用 Restricted Pod Security Standard 執行。範本也會說明擴充與備份方式，以及升級前要確認的事項，並用 `requires` 指名需要的元件。
