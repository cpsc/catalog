项目成员可以选择模板，将应用安装到单个 Namespace。每个模板固定镜像、设置资源请求与限制，并在可行时采用 Restricted Pod Security Standard 运行。模板也会说明扩容与备份方式，以及升级前要确认的事项，并用 `requires` 指定所需组件。
